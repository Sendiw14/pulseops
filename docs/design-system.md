# White Signal design system

- Canvas: `#F7F9FC`; primary surface: `#FFFFFF`; subtle surface: `#F3F6FA`.
- Text: `#111827`; secondary: `#475467`; muted: `#667085`.
- Border: `#E4E9F0`; subtle border: `#EDF1F5`.
- Primary action: `#345CFF`; selected tint: `#EEF3FF`.
- Positive, warning, and critical states use restrained emerald, amber, and red with accompanying labels/icons.
- UI font uses Geist; technical identifiers use Geist Mono.
- Prefer fine borders, minimal shadows, deliberate whitespace, tabular numbers, visible focus rings, and reduced-motion support.
- Demo telemetry must remain explicitly labeled; never style sample data to imply production health.
